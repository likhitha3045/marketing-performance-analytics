# Metric definitions

| Metric | Definition | Notes |
|---|---|---|
| CTR | Clicks / impressions | Platform delivery metric. |
| Session-to-order rate | Attributed orders / web sessions | The sessions table is campaign-keyed synthetic data. |
| CPC | Spend / clicks | Blended cost per click. |
| CPA | Spend / attributed orders | Uses order records and their campaign IDs. |
| ROAS | Attributed order revenue / spend | Revenue is gross order value in USD; not profit. |
| Engaged session rate | Engaged sessions / sessions | Supporting web engagement metric. |

Aggregate the raw totals first, then divide. Do not average campaign-day ratios to produce an overall rate.
