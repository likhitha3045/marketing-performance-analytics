# Data dictionary

All data is synthetic, generated by `src/build_dataset.py`, and uses USD.

## Source extracts

- `paid_media_daily.csv`: one row per reporting date and campaign; impressions, clicks, spend, and platform-reported conversion count.
- `web_sessions_daily.csv`: one row per date and campaign; sessions and engaged sessions.
- `ecommerce_orders.csv`: one row per order; order ID/date, synthetic customer ID, campaign attribution ID, gross order revenue, discount amount, and currency.

## Curated tables

- `dim_campaign.csv`: campaign attributes and illustrative daily budgets.
- `fact_campaign_performance_daily.csv`: one row per date and campaign, with delivery, web, and order totals joined at a consistent grain.

`platform_reported_conversions` is retained as a platform source metric but is not used for CPA or ROAS. Those use order rows to avoid mixing platform-defined conversion counts with order data.
